6mm push button housing by ringo2k on Thingiverse: https://www.thingiverse.com/thing:5487344

Summary:
This is an enclosure for a 6mmx6mm push button. I like the cheap buttons because of the the nice "push feeling". I wanted to have a base, which I can use to put these buttons on electronics housings. You need to print 3 parts: The base - There you put in the button (bend the legs and solder cables to it upfront)The pin - This is the pin, place it on the buttonThe housing - Put everything in the housing (super glue it together)That's it!
