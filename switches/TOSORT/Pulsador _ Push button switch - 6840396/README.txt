ESPAÑOLEl diseño 3D aquí recogido es un pulsador cuya fabricación requiere de la adquisición e integración de un interruptor de botón táctil y dos cables.Entre los ficheros, se recogen diferentes tamaños del soporte donde se pega el interruptor de botón táctil (H 4.3, H 5, H 6, H 7, H 8, H 9, H 10. H 11, H 12 y H 13). El número que acompaña a la H se corresponde con los milímetros de altura que tiene el interruptor de botón táctil, de forma que podamos imprimir la base que se corresponda con el que interruptor del que dispongamos. Tanto la pieza superior, como el botón son comunes para todas las bases. Se adjunta una presilla para los cables en caso de querer fijarlos de forma adicional a la soldadura de estaño y pegamento.Para conseguir un buen tacto en el pulsador, es imprescindible elegir la base con el tamaño adecuado, pues de no hacerlo, el pulsador no funcionará o no estará suficientemente ajustado y se bloqueará.Los interruptores de botón táctil recomendados para este proyecto son: https://www.amazon.es/dp/B0CPPJNMYF?ref=ppx_yo2ov_dt_b_fed_asin_titleLos cables pueden elegirse de cualquier tipo.Pulsador / Push button switch © 2024 by Adrián Álvaro Chumillas is licensed under Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International INGLÉSThe 3D design here is a push button that requires the acquisition and integration of a tactile button switch and two cables for its manufacture.Among the files, there are different sizes of the support where the tactile button switch is attached (H 4.3, H 5, H 6, H 7, H 8, H 9, H 10, H 11, H 12, and H 13). The number that accompanies the H corresponds to the height in millimetres of the tactile button switch, so that we can print the base that matches the switch we have. Both the top piece and the button are common to all the bases. A cable clip is attached in case you want to fix them additionally to the soldering and glue.To ensure a good feel on the push button, it is essential to choose the base with the appropriate size, as failing to do so will result in the push button not working or being insufficiently adjusted and getting stuck.The recommended tactile button switches for this project are: https://www.amazon.es/dp/B0CPPJNMYF?ref=ppx_yo2ov_dt_b_fed_asin_title.The cables can be of any type.Pulsador / Push button switch © 2024 by Adrián Álvaro Chumillas is licensed under Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International
