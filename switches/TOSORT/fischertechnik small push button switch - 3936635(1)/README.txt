Summary:
A small off/on or pole-reversing switch for the  fischertechnik  construction toy system. Uses a 8x8 mm push-button switch found as a no name item on ebay, I assume it's a K8-8081D-L1 from Korean manufacturer HRO.The off/on version needs no soldering. Simply cut off the middle contacts, bend the remaining four contacts completely flat and insert the switch into the base part, securing it with the sleeve part and, if needed, a drop of super glue.The pole-reversing version needs a bit of soldering, use the image provided as a guide. Watch out for the correct orientation when soldering, it only works in one way.
